# База данных библиотеки (PostgreSQL)

Учебный проект: проектирование реляционной базы данных книг, авторов, издательств, переводчиков и оценок, наполнение её данными и аналитические запросы. Финальный проект курса по SQL.

## Структура базы
| Таблица | Содержание | Связи |
|---|---|---|
| `publishers` | издательства | 1:N с `books` |
| `books` | книги: название, формат, страницы, дата выхода | FK на `publishers` |
| `authors` | авторы: имя, страна, дата рождения | N:M с `books` через `authors_books` |
| `translator` | переводчики | N:M с `books` через `translator_books` |
| `rating` | оценки книг | FK на `books` |

## Что реализовано
- **Проектирование (DDL):** первичные и внешние ключи; ограничения `CHECK` (формат книги, дата рождения в прошлом), `DEFAULT`, `NOT NULL`; связи 1:N и N:M через связующие таблицы.
- **Изменение данных:** `INSERT`, `UPDATE`, `DELETE`.
- **Запросы:** `JOIN` по нескольким таблицам, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT`, `LIKE`, `DISTINCT`, `CASE`, агрегаты (`AVG`, `ROUND`). Пример: рейтинг книг по средней оценке.
- **Представления:** постоянное (`authors_books_view`), временное (`books_ratings_view`) и CTE (`WITH`).
- **Оптимизация:** индекс по названию книги.
- **Хранимые процедуры на PL/pgSQL:** `add_author` и `add_book` для добавления записей.

## Пример запроса
```sql
-- Топ-5 книг по средней оценке
SELECT * FROM books_ratings_view
ORDER BY avg_rating DESC
LIMIT 5;
```

## Как запустить
Выполните `База Данных.sql` в PostgreSQL (psql, pgAdmin или DBeaver): скрипт создаст таблицы, заполнит их и выполнит запросы.
